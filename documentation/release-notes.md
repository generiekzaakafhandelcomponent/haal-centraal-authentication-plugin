# Release notes

Overzicht van wijzigingen per versie van de GZAC plugin-template.

Vanaf deze versie wordt de plugin op twee branches onderhouden: `main` (Valtimo 13, Java 21, gewone semver) en
`v12` (Valtimo 12, Java 17, semver met een `-V12` suffix). Zie de "Versioning & compatibility" sectie in de
README voor details.

## 1.0.0-V12 (branch `v12`)

Eerste release van de Valtimo 12 / Java 17 variant: backend omgebouwd naar Camunda 7.21.0 en
kotlin-logging 3.0.5 (`mu.KotlinLogging`), frontend plugin-library omgebouwd naar Angular 17.3.12 en
`@valtimo/*@12.40.0`.

## 1.0.0

Haal Centraal Authentication plugin: eerste werkende release, gebaseerd op de sample plugin uit de GZAC
plugin-template. Backend en frontend zijn geregistreerd en gebouwd getest.
