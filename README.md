# Haal Centraal Authentication Plugin

> [!WARNING]
> **Deprecated.** This repository is no longer maintained. Use
> [haal-centraal-auth-plugin](https://github.com/generiekzaakafhandelcomponent/haal-centraal-auth-plugin) instead
> (`com.ritense.valtimoplugins:haal-centraal-authentication` / `@valtimo-plugins/haal-centraal-auth`), which is the
> authentication plugin used by the
> [Haal Centraal plugin](https://github.com/generiekzaakafhandelcomponent/haal-centraal-plugin).
